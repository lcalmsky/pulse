# 예시 그림

README 가 쓰는 그림 목록입니다. 각 그림은 `scripts/demo.sh` 데모로 찍습니다.

- `menubar.png` 메뉴 막대 아이콘
- `popover.png` 팝오버
- `panel.png` 플로팅 패널
- `card-done.png` 끝남 카드
- `card-attention.png` 확인 필요 카드
- `card-stack.png` 여러 장 카드
- `settings.png` 설정 시트
- `deadhd-steps.png` deadhd 단계 펼침

영어판은 같은 그림을 `scripts/demo.sh start --lang en` 데모로 찍어 이름 뒤에 `.en.png` 를 붙입니다. 플로팅 패널은 `scripts/demo.sh start --many --lang en` 으로 찍습니다. `README.en.md` 가 이 8장을 씁니다.

- `menubar.en.png` 메뉴 막대 아이콘 (영어판)
- `popover.en.png` 팝오버 (영어판)
- `panel.en.png` 플로팅 패널 (영어판)
- `card-done.en.png` 끝남 카드 (영어판)
- `card-attention.en.png` 확인 필요 카드 (영어판)
- `card-stack.en.png` 여러 장 카드 (영어판)
- `settings.en.png` 설정 시트 (영어판)
- `deadhd-steps.en.png` deadhd 단계 펼침 (영어판)
